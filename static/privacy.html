Confidentialité

✅ Vous utilisez la version locale.
Vos fichiers sont traités directement sur votre machine (127.0.0.1) et ne transitent jamais par internet.

Traitement sur nos serveurs

Dans la version en ligne, vos fichiers sont envoyés sur notre serveur pour y être traités. Ils ne sont jamais partagés avec des tiers et sont supprimés automatiquement après traitement. Pour un traitement 100% privé, téléchargez la version locale.

Suppression automatique des fichiers

Les fichiers traités sont supprimés automatiquement de notre serveur après 1 heure. Vous pouvez aussi forcer la suppression immédiate via le bouton "Nouveau" après chaque traitement.

Aucune collecte de données personnelles

Nous ne collectons aucune donnée personnelle. Aucun cookie de tracking, aucun identifiant utilisateur. L'outil d'analytics Umami collecte uniquement des statistiques de navigation anonymes (pages vues, pays).

Bibliothèques utilisées

Le traitement des fichiers utilise uniquement des bibliothèques open source (Pillow, pikepdf, FFmpeg, pdf.js). Ces bibliothèques ne transmettent aucune donnée à des services externes.

Code source

FileLabs est entièrement open source. Vous pouvez inspecter l'intégralité du code sur GitHub.
